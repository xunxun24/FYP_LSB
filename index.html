1. The 8-Bit Pixel Standard

Each color channel (Red, Green, Blue) in a 24-bit RGB image is represented as an 8-bit unsigned integer V ∈ [0, 255]:

V = b₇·128 + b₆·64 + b₅·32 + b₄·16 + b₃·8 + b₂·4 + b₁·2 + b₀·1

2. LSB Bit-Swap (Light Encrypt)

Targets bits b₁b₀ (Weights 2 and 1). Performs deterministic symmetric swap:

IF (b₁b₀ == '10') THEN b₁b₀ = '01'
ELSE IF (b₁b₀ == '01') THEN b₁b₀ = '10'

Maximum Distortion: ΔV = ±1. Human visual system threshold is not reached. Image remains visually unchanged.

3. MSB Bit-Swap (Strong Encrypt)

Targets bits b₇b₆ (Weights 128 and 64). Performs deterministic symmetric swap:

IF (b₇b₆ == '10') THEN b₇b₆ = '01'
ELSE IF (b₇b₆ == '01') THEN b₇b₆ = '10'

Maximum Distortion: ΔV = ±64. High-energy visual frequencies are severely altered, creating strong visual static/noise.

4. Proof of Lossless Decryption

Since the bit swap mapping f(x) is an involution (its own inverse f(f(x)) = x):

Original (10₂) → Swap → 01₂ → Swap → 10₂ (100% Exact Restoration)
